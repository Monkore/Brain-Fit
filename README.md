🧠 BrainFit AI

**BrainFit AI** is an offline-first, AI-powered cognitive wellness platform designed to help seniors maintain and improve cognitive abilities, physical activity, emotional well-being, and daily engagement through personalized, accessible, and privacy-focused experiences.

The platform combines **cognitive training, wellness monitoring, adaptive recommendations, voice assistance, guided activities, yoga, pose detection, meditation, and progress analytics** into a single senior-friendly Android application. BrainFit AI is designed around the principle that cognitive wellness should be accessible, simple to use, personalized, and functional even without an internet connection.

### ✨ Key Features

* **Adaptive Cognitive Training** — Memory, attention, processing speed, executive function, language, and other brain-training activities.
* **AI-Powered Recommendations** — Generates personalized daily sessions based on user profiles, previous performance, wellness check-ins, and activity history.
* **Adaptive Difficulty** — Dynamically adjusts activity difficulty according to accuracy, performance, user feedback, and progression.
* **Daily Wellness Check-ins** — Tracks mood, stress, anxiety, energy, focus, motivation, mental fatigue, and sleep.
* **Offline Voice Assistant** — Uses Vosk for offline speech recognition with Android-native text-to-speech support.
* **Yoga & Pose Detection** — Uses MediaPipe-based pose tracking to provide feedback during physical activities and yoga exercises.
* **Safety-Aware Sessions** — Modifies planned activities when users report low energy, excessive stress, or fatigue.
* **Progress Analytics** — Tracks cognitive performance and generates understandable progress summaries.
* **English & Hindi Support** — Designed with multilingual accessibility in mind.
* **Privacy & Offline-First Design** — Core functionality is designed to operate locally using SQLite and on-device models.

### Technology Stack

BrainFit AI is built using **Python, Kivy/KivyMD, SQLite, Vosk, MediaPipe, OpenCV, and Android-native integrations**, with a modular Model-View-ViewModel / Service-Repository architecture.

The project is structured around independent **UI, services, repositories, AI engines, database models, analytics, and testing modules**, making it easier to maintain, extend, and introduce additional cognitive and wellness activities.

### Vision

BrainFit AI aims to create a **senior-first cognitive wellness ecosystem** where technology supports healthier routines without overwhelming users. By combining adaptive intelligence, accessibility-focused design, offline AI, and wellness-aware personalization, the project explores how mobile AI can make cognitive and physical wellness more approachable and privacy-conscious.
